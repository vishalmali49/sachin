# PROCUT SYSTEMS — Modern static website with local editor

## Preview locally
1. Extract this ZIP.
2. In this folder, run `python -m http.server 8000`.
3. Open http://localhost:8000

## Edit without a backend
- Click **Edit site** at the bottom-right.
- Click outlined text to edit it directly.
- Click an outlined image to enter an image URL or a relative image path.
- Enter the verified sales email in the editor panel.
- Click **Save changes** to save the edits in the current browser.
- Use **Export backup** to download a JSON file of your content/image edits, or **Import backup** to restore it.
- Use **Reset edits** to return this browser to the default content.

## Important limitation
This is a static website. Browser-local edits are only visible in the browser/device where they were saved; they do not update the deployed website for other visitors. There is no server or shared CMS. To publish edits for everyone, apply the content changes to the source files and redeploy, or add a real CMS/backend later.

## Before launch
- Replace stock photos with approved images of actual PROCUT SYSTEMS equipment.
- Verify product categories and specifications; the current product list is placeholder content.
- Add verified company address, telephone, email, service details, certifications, and warranty information.
- The enquiry form opens the visitor's email application using the sales email set in the editor; it does not store or submit leads on a server.
- External image URLs and Google Fonts require an internet connection.
